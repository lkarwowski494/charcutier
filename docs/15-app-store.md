## 3. Konfiguracja Sekretów CI/CD w GitHub Actions

Do automatycznego podpisywania i wysyłki do TestFlight wymagane są 4 sekrety w repozytorium GitHub (`Settings -> Secrets and variables -> Actions`):

1. **`APPLE_TEAM_ID`**: 10-znakowy identyfikator zespołu Apple Developer (np. `8NQ9GHY8GF`).
2. **`ASC_KEY_ID`**: 10-znakowy identyfikator klucza App Store Connect API (np. `2X9R4HXF34`).
3. **`ASC_ISSUER_ID`**: Identyfikator UUID wydawcy klucza API (np. `57246542-96fe-1a63-e053-0824d011072a`).
4. **`ASC_KEY_P8_BASE64`**: Zawartość pliku klucza prywatnego `AuthKey_<ASC_KEY_ID>.p8` zakodowana w Base64:
   ```bash
   base64 -w 0 AuthKey_2X9R4HXF34.p8
   ```

*Uwaga dotycząca bezpieczeństwa:* Potok `.github/workflows/testflight.yml` przestrzega rygorystycznych zasad bezpieczeństwa (`NFR-SEC-003`): klucz `.p8` jest dekodowany dopiero tuż przed eksportem archiwum z prawami `umask 077` i bezwarunkowo niszczony w kroku `always()`.
